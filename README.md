# 🛍️ BlackStore — E-commerce Website

**BlackStore** is a modern and responsive front-end e-commerce website designed to provide a simple and visually appealing online shopping experience.

The project was developed using **HTML, CSS, and JavaScript**, with multiple pages for browsing products, learning about the store, contacting the store, and accessing a login/registration interface.

---

## 🌐 Live Project

🔗 **GitHub Repository:**
https://github.com/Lakshya172/Project-2024/tree/main/E-commerce

---

## 📌 Project Overview

BlackStore is a fashion-focused e-commerce website that demonstrates the core concepts of front-end web development.

The website includes:

* 🏠 Home page
* 🛒 Product catalogue
* 👤 Login and registration interface
* 📖 About Us page
* 📩 Contact Us page
* 🎨 Responsive and modern UI
* ✨ Scroll and button animations
* 🖼️ Product and category image sections

The homepage presents featured and latest products along with promotional content and navigation to different sections of the website.

---

## ✨ Features

### 🏠 Home Page

The homepage provides an overview of the store and contains:

* Navigation bar
* Hero/banner section
* Product categories
* Featured products
* Latest products
* Special offer section
* Footer with useful links and social media sections

---

### 🛍️ Product Catalogue

The product page displays a collection of products with:

* Product images
* Product names
* Product prices
* Buy buttons
* Grid-based product layout

Example products include:

* Red Printed T-Shirt
* Black Shoes
* Sports Lower Wear
* Puma T-Shirt
* Watches
* Socks
* Casual Shoes
* Jockey Lower

---

### 🔐 Login & Registration

BlackStore contains a login and registration interface.

Users can switch between:

* Login form
* Registration form

The interface performs basic client-side validation to ensure required fields are entered before displaying a success message.

> **Note:** The current implementation does not use a backend authentication system or database. Authentication is currently implemented as a front-end demonstration.

---

### 📖 About Page

The About page explains:

* BlackStore's mission
* Store values
* Customer-focused approach
* Quality assurance
* Store story
* Community engagement

---

### 📩 Contact Page

The contact page provides:

* Name field
* Email field
* Message field
* Contact information
* Contact form interface

The current form is a front-end interface and requires a backend implementation for actually processing and storing submissions.

---

### ✨ Animations

JavaScript is used to provide interactive UI behavior, including:

* Scroll-based animations
* Button click animations
* Login/register form switching

The scroll animation is implemented by detecting when page elements enter the viewport and changing their opacity and position.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Lakshya172/Project-2024.git
```

### 2. Navigate to the Project

```bash
cd Project-2024/E-commerce
```

### 3. Run the Website

Since BlackStore is a front-end project, no database or server setup is required for the basic version.

You can simply open:

```text
index.html
```

in your browser.

For a better development experience, you can use **VS Code with the Live Server extension**.
